# CSM 텍스트 음성 변환 클라이언트-서버 시스템

이 시스템은 CSM 텍스트 음성 변환 모델을 백엔드 서버로 실행하고, 텍스트를 전송하고 오디오를 수신할 수 있는 클라이언트 애플리케이션을 제공합니다.

## 주요 기능

- 텍스트 음성 변환 요청을 처리하는 FastAPI 백엔드 서버
- 텍스트 전송 및 오디오 재생을 위한 GUI 클라이언트 애플리케이션
- CSM-1B(고품질) 및 gTTS(대체) 텍스트 음성 변환 엔진 모두 지원
- 콘텐츠에 맞는 적절한 음성을 선택하는 감정 분석
- 더 나은 음성 생성을 위한 문장 분할 기능
- 클라이언트의 한국어 인터페이스 지원

## 필수 요구사항

- Python 3.8 이상
- pip 패키지 관리자
- CSM 모델 사용 시: CUDA를 지원하는 GPU(권장) 또는 강력한 CPU

## 설치 방법

1. 필요한 의존성 패키지 설치:

```bash
pip install -r requirements.txt
```

2. CSM 모델을 위한 음성 샘플 파일 다운로드 (CSM 사용 시):

```bash
python start.py --download-samples
```

## 사용 방법

### 빠른 시작

서버와 클라이언트를 모두 시작하는 가장 쉬운 방법:

```bash
python start.py
```

### 백엔드 서버만 시작하기

1. 서버 시작:

```bash
python start.py --server-only
```

또는 직접:

```bash
python server.py
```

서버는 기본적으로 `http://localhost:5000`에서 실행됩니다. CSM 모델이 사용 가능한 경우 자동으로 로드하거나 gTTS로 대체합니다.

### 클라이언트 애플리케이션만 시작하기

1. 클라이언트 시작:

```bash
python start.py --client-only
```

또는 직접:

```bash
python client.py
```

2. 클라이언트 GUI 사용법:
   - 서버 URL 입력 (기본값: http://localhost:5000)
   - 텍스트 입력 영역에 변환할 텍스트 입력
   - 언어 선택 (영어 또는 한국어)
   - "gTTS 사용" 체크박스를 사용하여 더 빠르지만 품질이 낮은 음성 합성 선택 (한국어의 경우 자동으로 선택됨)
   - "음성 생성" 버튼을 클릭하여 텍스트를 서버로 보내 음성 생성
   - 오디오는 자동으로 재생되며, "최근 음성 재생" 버튼을 클릭하여 다시 재생할 수 있습니다

## API 엔드포인트

백엔드 서버는 다음 API 엔드포인트를 제공합니다:

### `/api/tts` (POST)

텍스트에서 음성을 생성합니다.

요청 본문:
```json
{
  "text": "음성으로 변환할 텍스트",
  "format": "wav" 또는 "base64",
  "use_gtts": true 또는 false,
  "language": "en" 또는 "ko"
}
```

응답 (format이 "base64"인 경우):
```json
{
  "success": true,
  "data": "base64로_인코딩된_오디오_데이터",
  "format": "base64"
}
```

## 문제 해결

- 서버가 시작되지 않는 경우 모든 의존성이 올바르게 설치되었는지 확인합니다
- CSM 모델을 로드할 수 없는 경우 필요한 음성 샘플 파일이 있는지 확인합니다
- 클라이언트가 서버에 연결할 수 없는 경우 서버가 실행 중이고 URL이 올바른지 확인합니다
- 한국어 TTS의 경우, CSM은 주로 영어로 학습되었으므로 gTTS 옵션을 사용하는 것이 좋습니다 (자동으로 설정됨)
